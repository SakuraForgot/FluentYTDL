# 应用语言与日志本地化

## 支持范围

应用仅支持简体中文 `zh_CN` 和英文 `en_US`，设置变更在重启后生效。
`auto` 对所有中文系统地区使用简体中文，对其他系统使用英文；旧 `zh_TW`、
`zh_HK` 等配置归并为 `zh_CN`，旧日语和其他语言配置归并为 `en_US`。
Fluent 控件与应用使用相同的归一化语言。保留 `en.qm` 和 `zh.qm` 地区回退别名。
音轨、字幕的语言标签和可选语言不受此限制。

应用文案、下载进度、通知、实时日志和带元数据的新历史日志按应用语言显示。
媒体标题、用户自定义账号名称、路径、格式编号、第三方输出、旧日志及没有可识别
元数据的日志保留原文。诊断日志的应用消息模板固定为英文，参数中的用户内容不翻译。

## 文案入口

| 入口 | 使用方式 | 契约 |
| --- | --- | --- |
| QObject 界面 | `self.tr("静态模板 {0}").format(value)` | 模板和类 context 必须可抽取；不要把调用藏在 f-string 内 |
| 服务、进度、动态词表 | `tr_text("静态模板 {0}", value)` | `RuntimeText` context；先翻译再格式化；词表通过显式 `QT_TRANSLATE_NOOP` 标记 |
| 普通日志 | `log_text(logger, "info", "静态模板 {0}", value)` | 英文诊断原文与语言无关参数；支持已有 `logger.opt(exception=...)` |
| 底层诊断异常 | `english("静态模板 {0}", value)` | Qt 无关，不依赖配置、日志或路径模块，避免启动导入环 |
| 更新器与 WebView2 子进程 | `standalone_text("静态模板 {0}", value)` | 从归一化环境变量读取语言，不引入 Qt |

`DisplayText` 保留模板及参数，支持复制。不要先插值再传给翻译函数，或把翻译后文案
用于配置值、业务分支、状态码、输出匹配。字幕、音轨、容器、下载状态继续使用原有稳定代码。
CleanLogger 的 `(状态码, 百分比, 显示文本)` 回调及 `fytdl` 事件字段契约不变。

主程序通过 `FLUENTYTDL_UI_LANGUAGE` 向更新器传递语言，兼容旧版更新器参数解析器；
新更新器也接受显式 `--language zh_CN/en_US`。`runtime_en.json` 由审校后的 Qt 目录生成，
独立更新器打包时包含此文件，不依赖 Qt。UAC 提权重启自身时显式携带语言参数，
避免环境重建丢失语言选择。

## 日志存储、回放与降级

- `app_YYYY-MM-DD.log` 保持原有 loguru 文本格式、异常堆栈和诊断用途。
- `display_YYYY-MM-DD.jsonl` 独立保存记录 ID、时间、级别、模块、消息 ID、参数和英文原文。
  消息 ID 是静态源模板 SHA-256 的前 20 位；源模板本身不写入元数据。模板修改后无法识别
  的历史 ID 回退到保存的英文原文，不猜测旧模板含义。
- 元数据与原日志都在午夜轮转、ZIP 压缩并保留 7 天；元数据不附加异常堆栈。
  参数执行凭据和用户主目录脱敏。初始化或写入失败不阻止业务及原日志写入。
- 实时已本地化记录走 `display_record_received`；无元数据记录走原 `log_received`，
  日志窗口只消费其中一路。`event_received` 继续独立传递既有结构化事件。
- 历史读取最多恢复 1,000 条元数据，按记录 ID 去重；坏 JSON 行和损坏 ZIP 被跳过。
  与原日志按时间、级别、模块和原文匹配；多行消息只在完整匹配时合并。
  旧日志、未知 ID、缺失元数据保留原文，不重复添加合成记录。
- 搜索同时匹配当前显示和英文原文；复制使用当前显示；诊断导出继续保留原始日志。
  高频下载进度仍只更新进度回调，不为翻译增加落盘事件。

## 更新与回归检查

```powershell
python scripts/i18n_update.py
# 审校并补齐两个 .ts；英文不能为空或保留 unfinished。
python scripts/i18n_audit.py --write-report
python scripts/i18n_release.py
pytest tests/test_i18n_integrity.py tests/test_i18n_runtime.py -q
ruff check src tests scripts main.py
ruff format --check src tests scripts main.py
```

格式调整会改变源码行号，应在格式化后重新抽取。不要手改生成的 `ui_text.py` 标记区、
`.qm` 或 `runtime_en.json`。修改 `.ts` 时可用 `scripts/i18n_ts.py` 保持 XML 格式。
CI 检查抽取/编译漂移、静态 `(context, source)` 覆盖、先插值再翻译、裸中文、占位符、
英文完成状态、`.qm` 逐条查译和发行资源语言集合。

## 消息中心补验

- 新内置通知在现有 `metadata_json.display_text` 中保留模板和参数，展示时按当前语言还原；
  不需要数据库迁移。已知旧更新/画质通知按完整模板兼容显示，不回写原记录。
  服务端公告和未知内容保留原文；损坏的模板元数据回退为原通知文本。
- 更新通知的操作入口统一为“设置 → 更新”，嵌套的版本类型和附加说明保留翻译信息。
- 浮窗宽度受屏幕限制，高度按内容计算；标题、操作行分开，按钮按文字尺寸布局。
  卡片标题和正文自动换行，时间独占一行；独立窗口支持窄宽度阅读。
- 公告详情尺寸跟随父窗口，正文独立滚动，并从开头显示。确认/关闭行为保持原有规则。
- 浅、深色英文页面完成 150% 离屏渲染检查；200% 下消息中心及公告测试 33 项通过。
  截图检查包含 380 逻辑像素宽的独立窗口、长标题、长正文和小窗口公告详情。

## 登录账号名称补验

WebView2 账号使用 `builtin_name` 区分自动生成名称和用户命名。新默认账号与未命名账号
保存稳定标识，显示时翻译；主动创建或重命名的非空名称保存为用户文本。
旧配置没有标识时，仅匹配已知完整名称，包括 YouTube/X 默认账号及其旧英文译名，
不按子串替换，也不为语言切换改写账号记录、ID、Cookie 或隔离存储路径。
设置页、登录提示和账号操作继续共用 `localized_name`。翻译、账号往返、用户重命名、
设置页下拉框和 WebView2 失败处理相关测试共 214 项通过。
