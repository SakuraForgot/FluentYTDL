## 产品方向

侧边栏新增 **媒体信息 / Media Info**，位于“任务”之后、“设置”之前。用户选择或拖入一个本地音视频文件，即可查看文件实际保存的标签与技术参数，尤其用于检查下载后的作者、日期、帧率、码率、音轨与章节。

首版同时支持视频和音频，因为现有元数据能力覆盖两类文件；页面名称保持“媒体信息”。本地读取不需要 YouTube 链接、登录、Cookie 或联网补全。它是独立查看工具，不修改文件，不创建下载任务。

| 决策 | 首版方案 |
| --- | --- |
| 输入 | 文件选择、单文件拖放、已完成任务右键直达；一次查看一个文件 |
| 输出 | 清洗后的内容、视频、音频、文件、来源、简介、章节等类型卡片；读取详情按需打开 |
| 重点格式 | MP4/M4A/MOV、MKV/MKA/WebM、MP3、FLAC、Opus、OGG；WAV 技术信息 |
| 技术参数 | FFprobe 读取；文件大小与时间来自文件系统；计算值单独标识 |
| 文本标签 | FFprobe 的容器/流标签，加已有 Mutagen 能力补充原生标签与 FluentYTDL 扩展字段 |
| 操作 | 选择/更换文件、取消、重新识别、复制单项、复制摘要、导出 JSON 报告 |
| 读取边界 | 展示读取到的结果和读取覆盖范围，不宣称完整解释任意容器的所有元数据 |
| 后续扩展 | 用户主动发起的逐轨码率/帧数全文件统计、批量比较 |

关键区别：**没有显示、读取器不支持、读取失败、文件标签未提供，是不同状态。** 页面不会仅凭缺少某个值断言下载器漏写，也不会声称没有帧数标签就没有视频帧。

## 第一版体验

1. 点击“媒体信息”，选择或拖入文件。
2. 先显示文件名、大小和读取状态；完成基础探测后展示时长、真实音视频流及可读取标签。
3. 在卡片中查看作者、日期、宽高、帧率、音轨等；去重、格式化单位，空值不占位。文件位置和修改日期保留在文件卡片。
4. “更多”中提供重试、复制摘要、读取详情和导出；导出选项仅在导出时显示。完整 JSON 保留来源和缺失原因。

**下载列表直达（首版）**：在“任务”列表对一个已完成任务右键，点击“查看媒体信息”，自动切换侧边栏至媒体信息页、载入该任务记录的主成品并开始识别，无需再次选择文件。重启后只有历史记录、没有 worker 的任务也支持。返回任务列表时保留原筛选、勾选及滚动位置。

文件已移动/删除或历史记录缺少成品路径时，在媒体信息页说明原因并提供手动选择入口；不会扫描目录猜测文件，也不会自动重下载或改写历史路径。

对于此前的 WebM 案例，预期能显示 VP9、3840×2160、约 23.976 fps、Opus/48 kHz/双声道和读到的作者标签；逐轨码率仍可能未提供。该案例是既有调查参考，不是本页已完成的运行验证。

## 本轮边界

已完成单文件、本地只读功能和任务右键入口，默认精简模式，可切换完整卡片。暂不加入标签编辑、自动修复、转码、播放预览、网络信息补全或目录扫描。3.7.5 按先合入 main、再通过线上 CI/Actions 构建和发布的顺序执行。
