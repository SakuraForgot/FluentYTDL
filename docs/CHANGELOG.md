# 更新记录

## v3.7.8-rc.1

本次预发布集中修复证书信任、网络请求和图片解码相关安全问题。

- 更新证书库，并过滤操作系统中仍残留的受影响信任根；软件更新和构建下载使用同一套信任规则。
- 升级 Python 3.12.15、Qt 6.12、Pillow 13 和 urllib3 2.8，更新内置 OpenSSL、Expat，并在打包前校验安全版本。
- 缩略图仅接受 JPEG、PNG、WebP、GIF 和 BMP；限制下载为 16 MiB、图像为 1600 万像素、请求为 30 秒，拒绝 SVG、EPS 等非预期内容。
- 重新发布并内置修复证书和网络依赖的 SABR Test 核心；POT 依赖修复重定向处理漏洞，保留上游服务与插件配对。

本版本为 Pre-release，不替代稳定版 Latest。**应用内更新不包含外部组件：升级后请在“设置 → 组件”更新 yt-dlp，并修复 POT Provider；也可使用本版本完整便携包或安装包覆盖升级。** 自定义核心路径由用户自行更新。配置、账号和下载记录保持保留。

## v3.7.7-rc.2

本次预发布迁移到 Brainicism 官方 POT Provider，并完善组件修复与加载状态提示。

- POT 服务与配套插件从官方上游获取，复用设置中的 Deno；移除旧版 Rust 服务相关插件，校验组件来源、版本和文件完整性。
- “设置 → 组件”增加 POT 的安装、更新、修复和启停操作；状态窗口可查看服务、插件与令牌检查结果，并执行检查或重启。
- POT 启用时，YouTube 解析等待实际令牌请求验证通过；加载失败会提示原因并提供重试，不再仅凭端口可访问判断就绪。
- 改善组件更新、POT 检查与下载任务之间的协调，取消等待及时退出，短暂文件占用和令牌请求失败可按规则重试。
- 修复软件更新检查时间未持久保存的问题，恢复跨启动的检查间隔；完善组件安装失败后的回滚与中英文提示。
- 修复发布测试中 Qt 应用实例混用导致的原生崩溃，补齐测试控件清理与卡顿诊断。

继续默认内置 SABR Test 核心，已有配置保持原选择。本版本为 Pre-release，不替代稳定版 Latest；旧用户需要在软件更新中选择 pre 通道。POT 令牌生成与 YouTube 解析仍受网络、代理及上游策略影响。

## v3.7.7-rc.1

本次预发布默认内置 SABR Test 核心，并整合 VR 解析与下载流程的改进。

- 新配置默认选择 SABR Test，便携完整版和安装包内置同一份经过来源、版本与 SHA256 校验的测试核心；仍可在设置中切回 Stable / Nightly / Master。
- 已有配置中的核心频道和自定义核心路径保持原选择。应用内更新只更新应用，旧用户如需使用 SABR Test，请在“设置 → 组件”选择该频道，再点击 yt-dlp 引擎的“立即更新”。
- SABR 测试核心沿用现有组件更新、POT 插件同步、Deno 与 FFmpeg，支持按实际文件哈希识别同日不同构建，并修复并行音视频下载的进度识别。
- VR 入口复用普通视频解析，将 VR 作为视频属性识别；仅在投影证据不足时补充 android_vr 探测，并在下载阶段按实际格式能力选择客户端。
- 改善 VR 音视频流合并、投影信息传递和下载选项，补充对应回归测试并同步中英文提示。

SABR Test 仍为测试核心，直播解析暂时受限；SABR 协议的分段下载、限速和并发参数受上游支持范围限制。本版本为 Pre-release，不替代稳定版 Latest；软件更新通道与核心频道分别设置。

## v3.7.5

新增媒体信息识别页，可以查看本地音视频的技术参数和已嵌入标签。

- 侧边栏新增“媒体信息”，支持选择或拖入单个本地音视频文件；下载列表中已完成的任务可右键直接查看成品信息，返回后保留列表状态。
- 默认精简模式按视频、音频卡片展示：视频包含分辨率、色度采样和位深、编码格式、码率、时长、色域；音频包含采样率、声道、音频码率、轨道时长。
- 可切换完整模式，查看标题、作者、年份、文件位置与修改日期、来源、备注、专辑、章节、字幕和封面等已读取信息；多条音视频轨道分别展示。
- 清理空值、无效日期与重复标签，统一单位；保留不同标题和多作者信息，缺失标签不从文件名或修改日期补造。
- 支持复制卡片、复制摘要、查看读取详情和导出 JSON；长内容按需展开，窄窗口自动切换单列布局。
- 识别过程只读，可取消或切换文件；导出报告避免覆盖源媒体文件。补充多格式读取、模式切换、任务右键入口和打包后标签读取的验证。

可显示的信息取决于文件内容及读取器支持；未提供的参数不会生成占位值。本版不编辑媒体标签，也不新增逐轨码率或总帧数的全文件扫描。

## v3.7.4

本版改进音视频元数据嵌入，修复部分 MP4 作者等信息写入失败的问题，并改善 YouTube 播放列表解析失败后的恢复与诊断。

- 下载完成后按实际媒体格式写入标题、作者、日期、简介及来源链接；支持 MP4/M4A、MP3、FLAC、Opus、OGG 与 MKV/WebM，具体字段取决于来源信息和容器支持。
- 区分视频频道、上传者与音乐作者，校验日期和年份；普通视频不再把分类当作音乐流派，也不把播放列表当作专辑。
- 修复部分含封面和预留元数据空间的 MP4 写入失败，解决视频可播放但作者、标题等信息缺失的问题。
- 元数据在媒体后处理完成后统一写入，检查写入结果后再采用新文件；写入失败保留原媒体，并提示未完成的元数据字段。
- 保留任务创建时的元数据开关，明确关闭的任务不受后续全局设置影响；章节按独立设置处理。
- 修复播放列表解析无法识别 yt-dlp 原始错误中 authcheck 恢复提示的问题；网页超时引发的错误优先显示网络原因，并说明浏览器 VPN 扩展与程序代理的区别。
- 补充多格式媒体、封面及章节保留的回归测试，增加打包自检中的元数据依赖验证，并同步中英文提示。

Windows 属性页对 WebM 等格式显示的字段取决于系统属性处理器。文件中已保留的帧率、分辨率或作者信息可能仍不显示；本版未新增逐轨码率统计，也不会自动修改此前已下载的文件。

## v3.7.3

本版修复 3.7.2 首次运行时 PO Token 插件目录缺失导致 YouTube 解析停止的问题（#100、#101、#102），并增强插件同步与恢复能力。

- 首次解析先部署并校验 POT 插件，避免新解压或新安装后出现“POT 插件目录不存在”。
- 按文件实际内容校验插件，自动恢复缺失、截断或被修改的文件，不再依赖历史同步成功状态。
- 插件写入使用临时文件校验和原子替换，短暂占用时自动重试，写入失败保留原文件。
- 安装目录不可写时直接加载随应用附带的插件，并优先使用已验证目录，避免旧的损坏副本抢先加载。
- 统一解析、下载、字幕及诊断入口的插件目录选择；切换 yt-dlp 内核后重新检查对应目录。
- 构建自检增加随包插件完整性检查，CI 增加真实 yt-dlp 插件导入回归测试。

本次修复针对插件部署与加载可靠性；YouTube 解析和 Token 生成仍受网络、账号及上游策略影响。

## v3.7.2

本版整合 3.7.2 预发布阶段的改进，作为稳定版发布。

- 新增“使用 YouTube Cookies”开关，默认开启；关闭后新解析使用无 Cookie 请求，保留已保存的账号和凭据。已创建的任务及重试保持创建时的模式，切换后请重新解析。
- 统一 yt-dlp 实际执行路径、版本显示和启动诊断；使用自定义内核时，明确区分正在使用的内核与组件更新的托管安装目录。
- 新配置默认启用 POT 服务；启用时首次 YouTube 解析等待服务就绪，加载失败明确提示。保留用户已有的关闭设置。
- 完善简体中文及英文界面、错误提示和菜单翻译，改善切换语言后的重启及界面布局。
- 改进会话日志、敏感信息脱敏、历史日志读取和诊断包，方便定位解析、下载及登录失败。
- 通知中心增加“全部清空”，集中显示刷新、全部已读及清空操作，并改善中英文布局。
- 完善 stable/pre 软件更新通道与公告展示；默认使用稳定通道，预发布更新需手动选择。
- 修正 yt-dlp 更新频道识别与切换，改善 GitHub 限流时的更新元数据备用源处理；安装包及组件文件继续通过 GitHub 下载。
- 改善 WebView2 登录组件加载失败和子进程退出的错误诊断，减少无效等待。
- 统一 Windows x64、Python 3.12.12 构建及安装流程，改进更新归档兼容性、独立更新器自更新和失败回退；发布时获取最新附加组件并校验来源与哈希。
- 安装器支持简体中文和英文，默认当前用户安装；覆盖安装及更新保留运行数据，卸载清理账号、配置和历史并保留下载成品。

YouTube 解析仍受网络、账号状态及上游策略影响；本版不保证消除所有机器人验证或页面重载错误。TikTok 等其他平台支持尚未加入。
