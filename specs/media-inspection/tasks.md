## 必测矩阵

| 场景 | 通过条件 |
| --- | --- |
| 完成任务右键；重启后无 worker 的历史行 | 一次点击自动切换到媒体信息页并读取记录的成品，无需重选文件；任务状态不变 |
| 右键多选、未选行、菜单期间新增/删除/重排任务 | 保留原勾选语义；多任务禁用；稳定身份检查保证不会读取错行 |
| 缺路径、文件被移动/删除、完成的字幕/封面任务 | 原因准确，无目录扫描、同名猜测或重新下载；手选文件不自动改任务记录 |
| 返回列表；连续查看 A/B | 原筛选和滚动位置保留，A 的晚到结果不能覆盖 B；多成品只承诺已记录的主成品 |
| MP4/M4A、MP3、FLAC、Opus、OGG、MKV/WebM、WAV | 对照已知样本显示容器、音视频流和对应标签；不支持的原生字段明确说明 |
| 原生标签很少或全部为空 | 技术信息仍正常，页面不把“无作者标签”误判为无效媒体 |
| 纯视频 MP4；有封面的音频 | 前者正确读取标签；后者不产生虚假的正文视频和帧率 |
| 多视频、多语言音轨、字幕、章节 | 逐轨独立显示，默认选取可解释，没有丢掉其他轨道 |
| 24000/1001、0/0、VFR、缺 nb_frames | 保留分数精度，未知不当作 0，不把参考帧率当平均帧率，不伪造帧数 |
| WebM 无 stream.bit_rate | 单轨明确未提供，总码率来源可解释；不从总码率倒推出单轨值 |
| 多作者、含逗号姓名、不同作用域标题、日期冲突 | 原始多值/作用域保留，差异可展开，无猜测性角色回填 |
| 中文/空格/emoji 路径，超长描述，未知/二进制标签 | 可读且布局正常；限制或截断明确，日志不带正文 |
| 空文件、损坏/加密/不支持文件、工具缺失、工具失败 | 稳定的原因与可操作提示；部分结果不被整体清空 |
| 连续换文件、取消竞争、关闭/托盘/重启 | 无旧结果覆盖、无遗留子进程、无运行线程被销毁；正常本地文件取消目标 2 秒内响应 |
| 非媒体输入、网络 URL、目录和多个文件 | 显式拒绝，不联网、不递归、不静默选首项 |
| 报告导出及同文件别名 | 来源、未知状态、原值完整；默认无绝对路径，不能覆盖媒体本体 |
| 只读验证 | 识别前后媒体 SHA256、大小及修改时间不变；只读权限文件成功，不比较可能变化的访问时间 |
| 原元数据写入回归 | 既有多格式、MP4 封面/padding、保真、取消、失败保留测试继续通过 |
| 打包后的主程序和辅助入口 | 两种模式均退出正确；辅助入口无第二个窗口、账号初始化和下载任务 |

技术测试、界面运行、冻结包运行分别记录；不能用单测通过替代 DPI、实际响应性和播放器/系统属性兼容结论。

## 交付与回退

首版交付条件：单文件只读查看及已完成任务右键直达链路、上述必要回归完成，报告明确来源和覆盖范围；完整统计、批量入口不作为首版完成前提。

实现按“模型/读取 → 原生适配 → UI/生命周期 → 报告/验收”拆分提交。回退时移除导航及独立服务入口即可停用查看功能；如果只读函数已被写入器复用，须保留兼容层或连同调用方一并回退，避免破坏 3.7.4 下载写入行为。用户媒体与下载历史没有迁移数据需要回滚。
