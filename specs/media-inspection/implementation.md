# 实施记录

2026-09-20，基线 3.7.4，分支 `feat/media-info`。

## 已实现

- “任务”后的媒体信息入口；本地文件选择、单文件拖入、重试、取消、六个视图、多轨切换、全文筛选、键盘选行和完整字段复制。
- 单个完成任务右键“查看媒体信息”，主窗口自动切换并读取有效主成品路径；历史行无 worker 也可用。返回使用同一个任务页面，不重建筛选和选择。
- FFprobe 技术探测与 Mutagen 独立原生标签辅助进程；程序早期 `--media-tags-worker` 分支在 GUI、单实例和账号初始化之前退出。辅助进程显式处理 Windows windowed 模式的继承管道。
- 一个活动请求加一个最新待处理请求；旧请求信号隔离。关闭到托盘保留作业，正常退出异步等待，aboutToQuit 提供重启路径的清理兜底。
- 读取器保留来源、作用域、原生键、多值和冲突候选；普通 artist 不推测作者角色。FFprobe 缺少帧数/轨道码率时不补造；总码率估算明确标注含容器开销。
- 后台 JSON 导出，默认不含路径和原始标签，拦截源路径与硬链接覆盖。二进制封面只报告摘要，不写入报告正文。
- 中英文目录及语言别名更新；冻结自检增加真实辅助子进程和继承管道往返。

## 与设计的实现取舍

保留 3.7.4 写入器不变，读取器复用其字段映射常量，新增独立的全标签枚举函数。没有为复用而重构已经发布的写入与校验流程。读取结果的数据类使用可序列化字段字典；原生与 FFprobe 的覆盖程度单独记录，缺失值为 null，不等于证明文件未嵌入。

首版仅实现快速读取。WebM/MKV/WAV 的原生标签覆盖标记为不支持，仍展示 FFprobe 返回的容器、流、章节及标签。恒定/可变帧率标记为未分析；没有扫描整段视频或伪装的深度扫描按钮。FFprobe 只允许本地 file 协议和指定媒体 demuxer，不加载播放列表。

进程 stdout 上限 8 MiB、stderr 上限 64 KiB，技术读取 60 秒、原生读取 15 秒；原生读取总字节也限 8 MiB。过大标签保留已读取技术信息并明确提示限制。媒体读取前后检查 size、mtime_ns 与文件身份；文件中途删除也返回已有技术信息和变更警告。

## 已知边界

外部进程可超时取消；本地文件系统的 OS stat/open 调用和用户指定报告目的地的写入不具备内核级中断保证。首版不支持 UNC 网络源文件。特殊设备/失联介质的系统调用延迟不能承诺等同正常磁盘上的取消响应。

下一版本未指定，暂不发布。后续发布顺序保持：功能合入 main → 指定版本与标签 → 线上 Actions 构建/发布。回退入口与独立服务即可停用功能，媒体和下载数据库没有迁移。
