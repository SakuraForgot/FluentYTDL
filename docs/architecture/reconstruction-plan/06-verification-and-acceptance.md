## 3. 反向扫描方法

先从已写的图和结论反找源码，再从全库重新抽取候选项查遗漏；两种方向都必须做。

1. 对每个 executable/特殊 flag，找解析位置、调用者、打包清单、退出路径。检查未打包入口和声明缺失目标。
2. 搜索状态赋值和 SQL update，再与转换表比对。UI 文案、进度、DB status、phase、outcome 分别检查。
3. 搜索所有 `connect`、QTimer、QThread/Thread、pool submit、Popen/run、multiprocessing，回溯创建者、所有者、退出与超时。
4. 搜索文件/目录写入、replace/unlink/rmtree、DB 提交、端口 bind/探测、环境/注册表访问，逐项比对资源表。
5. 搜索 retry/backoff/wait/while/recover，确认每个回环有取消出口；没有有限退出就解释由谁负责终止。
6. 分析 import 强连通分量但人工排除 TYPE_CHECKING、函数内延迟 import 和插件上下文；不能将 import 环直接等同初始化失败。
7. 对已有中英文架构、AGENTS/规则、注释逐段抽查。冲突以代码为依据，规范可能描述目标而非当前实现。
8. 对所有“唯一”“所有”“始终”“不会”词汇做逆例查找；没有覆盖全调用集合则缩小结论范围。

每个遗漏/错误建立 Finding，含原结论、反例、修订后的口径和回查证据。审查数量不是质量指标，应优先覆盖用户文件和账户、提交终态、进程所有权、更新回滚。

## 4. 需要时的分层验证计划

以下为后续 [RECOMMENDATION]，本次没有执行。现有测试是优先证据入口，不凭文件名保证它覆盖该机制；先读具体断言再选择运行范围。

| 层次 | 具体场景 | 有意义的观测 | 限制 |
| --- | --- | --- | --- |
| 纯静态 | 入口/调用/写入/清理/状态转换/文档漂移 | 文件符号、调用条件、哈希、反例 | 不证明 Qt 排程、Windows 锁或线上行为 |
| 现有隔离单测 | staging、observability、cookie runfile/mode、playlist authcheck、update transport | 对应断言、执行命令、通过/失败数 | Mock 返回不能证明真实 CLI 与远端相容 |
| 隔离故障注入 | 解析 worker 取消、挂起后 cancel、flush 失败、commit 时 shutdown | 槽位释放、有限退出、journal/产物/终态一致 | 不使用真实账户和下载目录；避免破坏性强停当前实例 |
| 本地受控运行 | 临时数据根、假 CLI/HTTP、迟到缓存、端口占用/复用 | 最终 argv、资源归属、残留、并发时序 | 假工具不代表真实 yt-dlp；仍可查我们自己的协议 |
| frozen/安装 | Unicode/空格路径、portable/installed、无 PATH、升级 READY 与失败回滚 | 最终包哈希、真实二进制、自检与启动结果 | 必须单独报告产品包与源码差异 |
| 外部/线上 | 真正解析/下载、更新服务、公告发布、跨账号认证 | 被允许的账户/目标、阶段、响应与文件 | 需要匹配明确任务范围；不由文档工作推导发布/写线上授权 |

测试隔离必须先于 import：`FLUENTYTDL_DATA_DIR_OVERRIDE`、Qt offscreen 等按项目 conftest 实现核实；认证根不一定随数据根变化，必须额外确认，不能仅设一个环境变量就假设没有接触真实认证材料。

## 6. 维护与漂移

正式知识库完成后，业务变动触及入口、状态、资源、错误/恢复或外部契约时更新相关实体与切片；纯展示文案变化仅在影响用户行为或本地化边界时修改运行说明。不能每次把整本书复制一份。

检查发现哈希漂移时，定位受影响章节和调用邻居，重新查实际语义；未影响的章节无需全部重写。新增结论保留作者、复核者、日期、源码基线、验证层次与未知项。既有证据快照只是时间点，不是永久架构保证。
