## 先抓住四组更值得做的改善

- **能结束**：三通道统一终态仲裁，取消唤醒所有等待；不把EOF非零或收尾错误错判成下载失败。
- **不串意图与身份**：用户意图与短期材料分开；旧解析结果不能污染新列表，选中账户不等于有效Cookie已切换。
- **不丢交付事实**：journal按发布阶段处理失败，未知现场保护，数据库保存失败不撤回用户成品。
- **有证据再提速**：先测重复解析、目录扫描、UI准入、工具probe和DB确认；默认TTL0及现有并发先保留。

每项详细建议包含现状源码、现有做法的价值、至少两种替代选择、推荐原因、代价、迁移回滚和验收条件。性能收益目前都是待验证假设。

本轮只新增这份方案及文档分析工具，未修改业务代码、运行产品测试、真实下载、构建或发布。已阅读的测试只作为资产与缺口证据；最终静态检查结果见[checks.json](evidence/checks.json)。
