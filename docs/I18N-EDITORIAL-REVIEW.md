# 中英文文案审校记录

2026-09-12：结合设置项、下载预设、错误诊断和按钮处理逻辑审校中文原文与英文译文。
逐项修订、原文和译文见 [i18n-editorial-review.json](i18n-editorial-review.json)。
记录包括 125 组中文源文案修订及 23 段帮助说明重写；目录项数量按语言和 context 分开统计，
不能视为独立功能数量。

## 主要修改

| 范围 | 原表述或问题 | 修订结果 |
| --- | --- | --- |
| 画质预设 | 720p 标清 / SD | 720p 高清 / HD |
| 下载格式 | 最佳画质（原盘） | 最佳画质（原始编码）/ Best Quality (Source Codecs)，解释保留源编码及播放支持条件 |
| 英文术语 | Pure Audio、Auto Infer、Encoding、Run Logs | Audio Only、Automatic、Codec、Application Logs；按实际控件含义使用 |
| 画质检查 | 风控、熔断、物理核验 | 下载画质检查、连续未达标暂停阈值、使用 FFprobe 核验分辨率 |
| 操作说明 | 清空缓存后“强制重新解析” | 清除缓存，下次解析时重新获取 |
| 自动更新 | 每 24 小时自动检查 | 启动时检查；24 小时内不重复检查 |
| Cookie | 过滤仅适用于 YouTube；过滤即“合规” | 说明 YouTube/X 平台过滤，移除无法保证的结论 |
| 错误诊断 | 403/429 即封禁、刷新 Cookie 保证恢复 | 区分请求拒绝和限流，给出可执行检查，不断言未知原因 |
| SABR | 断言画质存在，笼统说换档无用 | 明确缺少直接链接，仅切换画质不能解决；不推断源视频有哪些画质 |
| 格式兼容 | MP4 的 Opus/多音轨一定需转码或无法播放 | 说明编码、容器和播放器支持条件 |
| 帮助说明 | 99% 解决率、绝对兼容/恢复承诺、错误菜单路径、源码文字泄漏 | 重写 23 段双语说明，覆盖入门、格式、账号、组件、并发、恢复和问题反馈 |
