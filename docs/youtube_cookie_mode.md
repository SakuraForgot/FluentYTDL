# YouTube Cookie 模式与 yt-dlp 实际内核统一

日期：2026-09-13。实现已完成；以下明确区分代码验证、真实 CLI 样本与待完成的整机验收。未提交 Git，未发布、部署、更新或清理内核文件。

## 第一批：实际内核真相源

- `utils/ytdlp_runtime.py` 负责无 UI、无配置单例依赖的路径解析与版本探测；调用方传入显式配置，执行端保留兼容包装。
- 解析前置检查、CLI 执行、下载、POT 插件定位、组件状态和启动日志共用实际路径。保留既有搜索顺序及自定义路径行为。
- 版本由实际文件自身报告；按路径、文件大小、修改及创建时间缓存。文件替换、配置切换及组件更新不会借用其他副本的版本。缺失、未知、错误及超时有独立状态。
- 组件托管安装目标仍由依赖管理器负责，独立于实际执行路径。自定义内核状态显示实际路径与托管目标，更新提示明确只更新托管目录。
- 源规则在 `docs/RULES_EN.md` / `docs/RULES.md` 更新，生成的 AGENTS、CLAUDE 与 Copilot 规则通过 `scripts/sync_rules.py` 同步。

验收基准为项目根目录 `assets/bin/yt-dlp/yt-dlp.exe`，实测 `nightly@2026.08.30.232658`（上游提交 `bbc809a11`）。版本没有写入程序固定策略。其他内核副本保留原位。

自动覆盖：自定义路径优先、开发与打包候选、旧目录回退、PATH、执行/组件/启动共同身份、托管目标独立、替换文件后重探测、超时不回填 sidecar 版本。

## 第二批：Cookie 使用开关与请求模式

- 账号设置组中，在“Cookie 来源”前加入“使用 YouTube Cookies”，默认开启，中英文完整。关闭不会隐藏或禁用账号、导入及同步设置；提示重新解析应用新模式。
- `YtDlpAuthOptions.use_youtube_cookies` 在解析开始时固定；结果、子条目和任务通过 `__fluentytdl_youtube_cookies_enabled` 传递模式。该字段不包含 Cookie 内容，不传入 yt-dlp。
- 普通、VR、频道、播放列表、条目懒加载及手动重试保留启动时模式。下载窗口沿用解析模式，队列通过现有 `ydl_opts_json` 持久化；历史任务首次恢复时采用当前设置并保存。
- 关闭模式在共享构建层禁止直接文件与 Sentinel 注入，在下载参数合并及 CLI 边界再次约束；字幕迟解析和轻量字幕/封面请求避免 Cookie 回填。纯图片直链保持原有不注入 Cookie 的路径。
- YouTube 缓存身份包含模式、代次、Cookie 指纹与客户端参数；切换清空解析缓存，旧代次请求可向原窗口返回，但不能回写新代次缓存。
- SABR 读取、打标和单次追加重解析使用实际请求的账号或匿名会话上下文。关闭但仍选有账号时，仅标记匿名会话。匿名解析不会执行刷新 Cookie 型恢复；需要认证时提示开启设置后重新解析。
- POT、手动 Token 和 JS 配置保持独立。无 Cookie 普通视频沿用内核默认客户端；未新增 `default,-web`，未在登录态强行追加 `visionos`，VR 专用策略保留。非 YouTube 请求继续原行为。

专项自动覆盖：直接/Sentinel Cookie 拒绝、合并后 CLI 约束、X 平台不受开关影响、工作线程快照、播放列表子条目标记、切换中旧缓存写入拒绝、匿名 SABR 隔离、POT 独立失败语义、字幕迟解析、设置页实际鼠标切换、文件与账号来源保留、队列数据库往返、历史恢复与匿名错误不刷新 Cookie、手动重试保持原模式。
